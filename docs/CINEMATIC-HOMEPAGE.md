# Cinematic Homepage 3.0

## Goal

Chat 8 turns the homepage into a complete premium brand narrative rather than a collection of strong but separate website sections.

The homepage should move a visitor through this sequence:

1. introduction / visual impact
2. point of view
3. signature work
4. photographic detail
5. broader portfolio proof
6. service experience
7. artist credibility
8. client trust
9. Journal authority
10. booking invitation

The order matters.

## Narrative structure

### 00 — Introduction

The hero is intentionally cinematic:

- one primary portrait
- one smaller secondary image accent
- oversized display typography
- service-area context
- two restrained actions
- editorial signature type over photography

The hero should create desire before explaining everything.

### 01 — A quieter kind of luxury

The manifesto explains the artist’s approach.

This section should answer:

- what does the artist believe?
- how should the makeup feel?
- what makes the work different?

Keep it concise.

### 02 — Signature story

The first selected Home Portfolio project becomes a full-screen project moment.

It uses:

- full-background project photography
- project category
- title
- excerpt
- a smaller detail image when available
- direct link to the complete project story

This is the first major proof point on the homepage.

### 03 — In the details

A short image essay is automatically derived from selected Portfolio project galleries.

The goal is visual pacing:

- preparation
- portrait
- detail

This chapter should not become another project grid.

### 04 — Selected beauty stories

The homepage then shows several additional projects in an asymmetric editorial layout.

The full Portfolio remains the destination for deeper browsing.

### 05 — The experience

Services are presented as an experience rather than a price list.

The first selected Service provides the sticky photography stage.

The following selected Services become the ordered service list.

### 06 — Behind the work

The About global feeds an artist-profile chapter directly into the homepage.

It uses:

- artist portrait
- About eyebrow
- About heading
- About lead
- up to three credentials
- link to the full About page

This makes the artist visible before asking the visitor to trust the booking process.

### 07 — Client notes

Up to three testimonials appear as a composed trust sequence.

The selected Home testimonial is prioritized first.

Other real testimonials automatically fill the remaining spaces.

### 08 — From the Journal

The newest three public Journal posts are surfaced on the homepage.

This chapter supports:

- expertise
- SEO discoverability
- internal linking
- client education
- authority beyond portfolio imagery

### 09 — Availability

The final CTA becomes a full-photography closing scene.

It uses the Home closing CTA copy and a strong Portfolio image.

This is intentionally the strongest conversion moment on the homepage.

## CMS art direction

### Featured Projects

Select 4–6 strong projects.

Order matters:

1. first project → Signature Story
2. following projects → photography essay / Selected Work

If fewer projects are selected, real published projects fill the remaining positions automatically.

Real CMS content always takes priority over demo content.

### Featured Services

Select 4–5 services.

Order matters:

1. first service → sticky visual stage
2. following services → list sequence

### Featured Testimonial

Choose the strongest client quote.

It is prioritized first in the homepage Client Notes sequence.

Other real testimonials fill the remaining spaces.

### Hero image

Use one exceptional portrait.

Recommended:

- 2:3 or 4:5 source
- strong face
- controlled background
- room for typography
- accurate alt text
- high-resolution original

### Closing CTA

Keep the closing copy direct.

The visitor has already seen:

- work
- process
- services
- artist
- testimonials
- Journal

The final section should ask for the enquiry rather than introduce new information.

## Mobile behavior

Mobile is intentionally re-composed.

- Hero copy appears before the main image.
- Secondary hero photography becomes a small floating accent.
- Signature Story becomes a full-height photographic chapter.
- Portfolio asymmetry resolves into a clean linear sequence.
- Sticky Service imagery becomes normal flow.
- Client Notes become stacked editorial quotes.
- Journal becomes a linear story sequence.
- Closing CTA remains a large photographic finish.

Do not reduce display typography simply to make the mobile page feel more conventional.

## Content fallback

The homepage is CMS-first.

Real Portfolio projects, Services, testimonials, About content, and Journal posts take priority even when they are not explicitly marked Featured.

Demo content is used only when the corresponding real collection/global has no meaningful content.

## Performance and accessibility

- Hero photography uses Next.js Image priority.
- Other photography is responsive and lazy by default.
- No animation library is required.
- Existing reduced-motion rules remain active.
- Semantic headings and links remain intact.
- The design remains fully CSS/CSS Modules based.
- Tailwind remains prohibited.
