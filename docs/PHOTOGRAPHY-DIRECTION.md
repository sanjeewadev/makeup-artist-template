# $2K Photography Direction

## Goal

The website should feel as though one beauty art director, photographer, and makeup artist planned the complete visual language together.

Chat 7 therefore treats photography as a system rather than a collection of interchangeable portraits.

## Target library

A premium real-client launch should aim for roughly 35–50 strong photographs across these families:

- 8–12 finished bridal portraits
- 6–10 editorial / beauty portraits
- 5–8 artist-at-work / makeup application frames
- 4–6 getting-ready / preparation frames
- 4–6 close details: eyes, skin, lips, jewelry, veil, hands
- 3–5 wide environmental frames
- 3–5 tools / palette / atmosphere still lifes
- 2–4 monochrome or quieter transition images

The demo layer currently mirrors this density with a curated Pexels-based library.

## Shot hierarchy

### Hero portraits

Purpose:

- homepage opening
- portfolio lead project
- major service / campaign moments

Recommended framing:

- 2:3 or 4:5 portrait
- clear face
- quiet background
- enough negative space for editorial composition
- strong skin detail
- intentional eye line

Avoid using the same hero portrait in more than two high-visibility sections.

### Finished beauty portraits

Purpose:

- portfolio archive
- project galleries
- Journal covers
- testimonial/supporting imagery

Recommended framing:

- 2:3
- 4:5
- occasional square beauty crop

The face should remain the main subject. Avoid uncontrolled backgrounds that make the website feel like a random social-media feed.

### Artist-at-work photography

Purpose:

- About
- Journal
- project/process stories
- service credibility

Capture:

- brush application
- eyeliner/lash detail
- skin preparation
- final touch-up
- working posture
- artist/client interaction
- mirror moments

These images add commercial credibility because they show the service experience, not only the result.

### Getting-ready photography

Purpose:

- bridal story pacing
- wedding morning narrative
- Journal content
- service presentation

Preferred frames:

- wider room scene
- hands / tools
- seated bride
- artist interaction
- wardrobe/jewelry preparation
- calm candid moment

Use these to create breathing room between close beauty portraits.

### Detail frames

Purpose:

- editorial pacing
- mobile transitions
- portfolio galleries

Useful details:

- eye makeup
- lips
- skin texture
- jewelry
- veil
- lashes
- brushes
- palettes
- hands
- product texture

A premium gallery should not be ten similar face portraits in a row.

### Wide frames

Purpose:

- full-width project gallery moments
- page transitions
- environmental storytelling

Recommended ratios:

- 3:2
- 16:10
- 16:9

Wide images should be intentionally horizontal rather than heavily cropped portrait images.

### Still life / tools

Purpose:

- Journal
- portfolio transitions
- consultation / preparation stories

Use selectively. These images support the story but should never become generic beauty-blog decoration.

## Recommended image ratios

### Primary portraits

- 2:3
- 4:5

### Editorial portrait variation

- 3:4
- 1:1 where the crop is deliberate

### Wide storytelling

- 3:2
- 16:10

### Details

- 4:5
- 3:4
- square when the subject supports it

Do not upload every image as a square.

## Resolution

For a real client library:

- aim for at least 3000 px on the long edge
- keep original high-quality JPEG/WebP/AVIF source files
- avoid screenshots
- avoid images downloaded from social media
- avoid repeatedly re-exported compressed files

Payload/R2 should receive the best available original file.

## Color direction

The website is built around:

- warm skin
- restrained neutrals
- ivory / cream
- black
- warm clay
- muted rose
- occasional stronger editorial color

A complete gallery can include color variation, but avoid mixing completely unrelated presets in one project.

A single project should feel like one photographic story.

## Image density by page

### Home

Use approximately:

- 1 hero
- 3 photography-essay images
- 3 selected-work images

The homepage should preview the visual world rather than show the entire portfolio.

### Portfolio index

Use one strong lead image per project.

Avoid choosing five almost-identical close-ups as consecutive cards.

### Project page

Ideal:

- 1 hero
- 4–8 gallery images

Recommended sequence:

1. finished portrait
2. preparation/detail
3. wider frame
4. second portrait
5. close detail
6. final wide/editorial image

### Services

One strong service image per service.

Photography should communicate the actual experience:

- Bridal → preparation / finished bride
- Engagement → polished portrait
- Editorial → studio beauty
- Occasion → glamour/evening portrait
- Bridal party → group-preparation atmosphere

### About

Prefer a real artist-at-work portrait over a generic headshot.

The artist should look active, credible, and connected to the work.

### Journal

Use article-specific imagery.

Do not use the same bridal hero image as the cover for every educational article.

## Client replacement workflow

When converting the demo into a real artist website:

1. upload the real photography to Payload Media,
2. write accurate Alternative Text,
3. add photo credit when relevant,
4. assign one strong hero per Portfolio project,
5. create galleries with varied portrait/wide/detail images,
6. replace About with real artist photography,
7. replace Service images deliberately,
8. replace Journal covers,
9. inspect desktop and mobile crops,
10. remove weak or repetitive images rather than trying to use everything.

## Quality rule

More images do not automatically create more value.

The premium rule is:

**more visual variety, fewer weak photographs.**

A 40-image library where every frame has a role is more valuable than 100 random photos.

## Demo boundary

The demo library is presentation content only.

It must never be represented to a real client as the makeup artist’s own work.

Real client content should replace it before the website is publicly marketed as that artist’s portfolio.
