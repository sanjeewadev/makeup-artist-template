# Portfolio as the Main Sales Weapon

## Goal

Chat 9 turns the Portfolio from a polished gallery into the strongest proof and sales surface on the website.

The Portfolio should answer four questions without sounding like a sales page:

1. Is the artist’s work consistently strong?
2. Can I find work that feels relevant to my occasion?
3. Can I understand the thinking and experience behind the finished look?
4. If I like this direction, is there a clear next step?

## Portfolio index structure

### Hero

The opening establishes the Portfolio as a body of work rather than a social-media gallery.

It communicates:

- complete visual stories
- multiple categories of work
- total project depth

### Portfolio cover story

The first featured project becomes the Portfolio cover story.

If no project is explicitly Featured, the first real project is used.

The cover story includes:

- primary hero image
- secondary gallery detail image
- category
- title
- excerpt
- location
- year
- total story-frame count
- direct project CTA

The cover should feel like opening a beauty publication.

### Archive context

The archive begins with an editorial introduction rather than dropping immediately into filters.

### Category filtering

Filters show:

- All
- each populated category
- project counts

The selected filter also shows:

- category title
- category description
- visible story count

Category descriptions are therefore useful public content, not just internal admin notes.

### Project cards

Portfolio cards communicate more than a title.

They can expose:

- category
- project title
- year
- location
- story-frame count
- excerpt on larger editorial cards

The layout remains intentionally asymmetric.

## Project case-study structure

### Hero

Each project opens with:

- Portfolio back link
- current project position, e.g. Story 03 / 10
- category
- title
- excerpt
- client/project name
- location
- date
- story-frame count
- large hero photography

This helps a visitor understand the work before scrolling into the gallery.

### Direction

The project Story content is treated as a short case study.

Recommended content:

- occasion or creative brief
- desired feeling / level of polish
- skin and finish direction
- photography/light considerations
- why the final choices worked

A sticky Project Notes rail summarizes category, setting, and image-story depth.

### Visual study

The gallery is a sequence, not a dump of images.

Recommended order:

1. strong finished portrait
2. preparation/process
3. detail
4. wider storytelling frame
5. second finished portrait
6. final editorial or atmospheric frame

Use 4–8 strong images rather than uploading every available photograph.

### Full-screen viewer

Gallery images can be opened into a full-screen viewer.

The viewer includes:

- native modal behavior
- Escape-to-close
- previous / next image navigation
- image position
- caption
- photographer credit
- responsive image sizing
- keyboard-focus states

No third-party gallery library is required.

### Enquiry bridge

The conversion copy responds to the project the visitor just viewed.

The message is intentionally:

“Drawn to this kind of finish?”

rather than a generic “Contact us”.

It invites the client to describe:

- the feeling
- texture
- polish
- visual direction

they were drawn to.

### Continue the Portfolio

Projects end with previous and next story navigation using large photography.

The goal is continuous browsing, similar to moving through a book.

For a two-project portfolio, only one neighboring project is shown to avoid duplicate previous/next links.

## CMS editing rules

### Hero image

Choose the strongest finished portrait.

Prefer:

- 2:3 or 4:5 source
- high-resolution original
- clean background / composition
- strong skin detail
- intentional crop

### Excerpt

Write a 1–2 sentence visual hook.

Good excerpt topics:

- finish
- light
- mood
- occasion
- desired feeling

Do not write generic marketing copy.

### Story

Treat Story as a compact case study.

Explain enough to give the work meaning, but do not turn it into a long blog article.

### Gallery

Aim for 4–8 frames.

Mix:

- finished portraits
- preparation
- application
- eye/skin/jewelry details
- wider environment
- quieter transitional images

Use gallery Presentation only as an art-direction hint.

### Category descriptions

Keep category descriptions concise and useful because the Portfolio archive displays them publicly when that filter is selected.

## Sales rule

The Portfolio should persuade through evidence.

Avoid:

- fake awards
- fabricated client logos
- aggressive sales copy
- unnecessary pricing banners
- “book now” buttons after every image
- excessive badges
- numerical claims the artist cannot support

The premium feeling comes from the quality, depth, context, and presentation of real work.
